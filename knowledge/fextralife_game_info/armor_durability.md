# Demon's Souls Armor Durability Values

> Source: Fextralife Demon's Souls Wiki — the four armor category pages linked from the [Armor Set](https://demonssouls.wiki.fextralife.com/Armor+Set) hub page. Values are the `Durability` column from each page's stats table, transcribed verbatim.

- [Armor Set](https://demonssouls.wiki.fextralife.com/Armor+Set) — set gallery (no stats)
- [Helms](https://demonssouls.wiki.fextralife.com/Helms)
- [Chest Armors](https://demonssouls.wiki.fextralife.com/Chest+Armors)
- [Gauntlets](https://demonssouls.wiki.fextralife.com/Gauntlets)
- [Leggings](https://demonssouls.wiki.fextralife.com/Leggings)

## Notes

- Durability is the in-game maximum condition value for each armor piece (the value a repaired piece returns to).
- A few pieces list `0` (e.g. *Monk's Head Collar*); these are non-repairable / have no degradation mechanic. The `0` is recorded verbatim from the wiki, not inferred.
- Remake-exclusive pieces (e.g. *Blue-Eye Knight* set, *Penetrator's* set, *Burrower* set, *Official's* pieces) are included because they appear on the same wiki category pages.
- Names are kept exactly as printed on the wiki, including apostrophes and possessives.
