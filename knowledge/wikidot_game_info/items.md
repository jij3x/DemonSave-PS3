## 1. Armor

There are **nineteen separate armor sets** and **three unique equipment pieces**. All items are interchangeable, except those that are gender-specific. Some items are available to both genders but are slightly different in appearance for male and female characters; those identical in appearance are labeled as unisex.

### Stat Key / Legend

| Stat | Description |
|------|-------------|
| **Physical** | Physical defense against: Normal / Blunt / Slashing / Piercing |
| **Magic** | Magic defense |
| **Fire** | Fire defense |
| **Bleed** | Bleed resistance |
| **Poison** | Poison resistance |
| **Disease** | Disease (Plague) resistance |
| **Weight** | Weight of the individual piece. Equipping >50% of Equip Weight reduces roll speed; >100% reduces movement to walking. |
| **Stam Pen** | Stamina regeneration penalty: 1 (minimal) to 5 (severe). Higher values mean slower stamina recovery. |
| **Gender** | **Both** = unisex; **Male Only** / **Female Only** = gender-restricted |
